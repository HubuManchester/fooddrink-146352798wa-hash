# NutriTrack - Food & Drink App

A .NET MAUI mobile app for tracking food and drink nutrition.

## Features

- Browse food/drink list (cloud data from mockapi.io)
- Search by name, category, or tags
- Add new food with validation
- View nutrition details (calories, protein, carbs, fat)
- Hardware demo: Camera, Location, Text-to-Speech, Vibration, Haptic Feedback
- Dark/Light theme + Large text mode

## How to Run

1. Open `FoodDrinkApp.sln` with Visual Studio 2022
2. Select Android Emulator or Windows Machine
3. Click Run (F5)
